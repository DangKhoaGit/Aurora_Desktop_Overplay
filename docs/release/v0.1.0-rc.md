# Aurora Desktop Overlay v0.1.0 — Release candidate checklist

## Phạm vi MVP

- Import PNG/JPG/BMP/GIF.
- Move, resize giữ tỷ lệ, opacity, lock, click-through và always-on-top.
- Nhiều overlay, GIF playback/FPS, multi-monitor/DPI.
- Autosave/restore, system tray, global hotkey, startup cùng Windows.

## Release gate

- [x] Chọn và thêm `LICENSE` — GNU GPL-3.0.
- [ ] Hoàn thành manual matrix trong `docs/checker/sprint-6-check.md`.
- [ ] Không còn issue P0/P1; issue P2 có workaround/owner.
- [ ] Portable và installer smoke test trên máy sạch Windows 10/11.
- [x] Xác nhận silent install, smoke test và uninstall; dữ liệu `%LocalAppData%\AuroraDesktopOverlay` được giữ lại.
- [ ] Điền benchmark CPU/GPU/RAM và soak 8 giờ.
- [x] Chốt phát hành `v0.1.0` unsigned; SHA-256 của portable và installer đã được xác minh.
- [ ] Tag `v0.1.0-rc.1`, kiểm tra workflow; sau sign-off mới tag `v0.1.0`.

## Release notes draft

ADO v0.1.0 là MVP đầu tiên cho phép đặt nhiều ảnh/GIF trong suốt trên Windows desktop, chỉnh layout, click-through, always-on-top và tự khôi phục session. Xem `docs/known-limitations.md` trước khi dùng với game/fullscreen.

## Chính sách unsigned của v0.1.0

- Chỉ phát hành artifact qua GitHub Release chính thức của dự án.
- Đính kèm file `.sha256` cho portable ZIP và installer.
- Release notes phải ghi rõ ứng dụng chưa ký số và Windows SmartScreen có thể cảnh báo.
- Tag chứa source tương ứng phải được giữ public theo GNU GPL-3.0.
